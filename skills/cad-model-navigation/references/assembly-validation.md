# Checking a saved assembly

1. **Identify each installation.** Record the definition ID and file hash once. For each installed occurrence, record the parent, readable name, role, native layer, local transform and units. For a nested feature, compose the parent transforms before comparing its world position. Try a lookup on each of two identical parts. When a source gives only their common definition, use the owner’s mounting position or ask which installation is intended.
2. **Separate material evidence.** Record the source material term on the body and read it back after saving. Identify whether the application preserved a text property, a native material assignment, or a face appearance. Keep density and finish empty unless sourced. A false material injected into a test receipt exercises the verifier only. On exchange, inspect the reopened destination for each required field and keep any companion file identified by format and revision.
3. **Check the modeled joint.** For a Boolean cut, identify the receiving body again after subtraction. Derive expected seat corners from the source profile, placement and datum. Read the receiving solid's actual vertices after reopening. Compare in the same frame and units using the job tolerance. Inspect the exposed seat before restoring the mating member. Also check solid topology and placement when the handoff requires them.
4. **Check native visibility.** Hold the camera fixed through full, isolated and restored views. Record both the native visible members and what the viewport shows. If comparing images, use the geometry region and exclude menus, selection grips, cursors and command text. Record the threshold, changed pixels and residual after restoration. Set the close-up camera on the joint, qualify the empty and isolated views, then check them in the decoded recording. Keep projection drawings and native viewport evidence identified separately.
5. **Record a live demonstration when requested.** Use an owned drawing and display. Test a short clip before the build. Record the actual commands and acknowledgements as they happen. Link chapters to elapsed operation times. Decode the complete file, inspect representative frames and align the final selection with the reopened document’s occurrence ID. Keep paths, credentials and unrelated windows outside the capture.
6. **Verify catalogue handoff.** Record the catalogue repository revision, definition ID, model SHA-256 and dependency hashes. Query the actual target index by ID and record which dataset returned it. Report a validation draft, a main-index record and a published release separately. Keep installed poses and project names in the consuming assembly. Test filters against sourced properties, including an unknown material.

For a constant-frame-rate capture, run the [recording checker](../scripts/check_recording.py) with the movie and a JSON receipt containing a `chapters` list of `title` and elapsed `seconds` values. It uses local ffprobe and ffmpeg to check presentation intervals, chapter order and bounds, and decoding. Actual build actions and visibility require the native and visual checks above.
