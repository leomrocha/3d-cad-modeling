# Source-bound annular reference solids

Use [`annular_reference.py`](../scripts/annular_reference.py) when a component source defines a plain ring by bore diameter, outside diameter and axial thickness.

1. Supply an external source job with `geometry_role: reference_annulus`, `units: mm`, a readable part identity, representation, job ID, metadata application name, frame description, local-frame description, two-coordinate `center`, and `z_origin`.
2. Bind `dimension_features.bore_diameter`, `outside_diameter` and `thickness` to three distinct required feature names. Each feature carries its numeric value in millimetres, source locator and SHA-256, source location and evidence status. Resolve portable source locators through an explicit caller-supplied root map before calling the helper.
3. Supply `construction.cutter_overrun_mm` as a positive finite construction input. It extends the bore cutter beyond both axial faces; it does not change the source thickness. The helper rejects numeric overflow or coordinate collapse before creating the OCS Geometry adapter.
4. `build_annulus` creates an outer cylinder, a concentric bore cutter and one boolean subtraction, then writes ordered source metadata. The component local axis is +Z and the outer cylinder's lower face is at `z_origin`; assembly placement remains a separate operation.
5. `verify` checks the outer and inner analytic cylinder radii/axes, rejects additional cylinder/plane/cone/sphere surfaces, checks the two annular end-face stations, requires a face with multiple boundary loops at both end stations and checks one closed connected body. Supply `planar_face_loops` from the supported SAB reader with loop inclusion enabled. It does not use circle seam vertices as diameter measurements. `inspect` reads one actual reopened `Solid3D`, binds checks to its document and geometry revisions, requires SAB and planar loops, and compares stored metadata under the adapter's fixed `CADTOOLS_SOURCE` application. `verify_metadata` uses [`source_metadata.py`](../scripts/source_metadata.py).
6. The result represents a nominal annular solid. Add radii or chamfers only when the source job binds those features; this helper does not add them. Source dimensional limits and native comparison tolerance remain separate inputs.

Synthetic tests cover parameterized cylinder/subtraction calls, invalid-input rejection before geometry creation, analytic feature comparisons, body topology and stored metadata comparisons. They do not establish a physical component's fit or manufacturing tolerances.
