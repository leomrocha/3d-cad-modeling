# C054 — Victron smallBMS NG saved-geometry comparison

The official Rev00 dimension drawing identifies `BMS400100300 smallBMS NG`, states millimetres, and gives the housing envelope as 107 × 46 × 23 mm. Its mounting detail gives 97 mm slot-axis pitch, 12 mm slot-end-arc centre separation, `R1.75 (4x)`, and 3 mm mounting-foot thickness. The STEP AP214 file is linked from the same official product page and contains nine placed solids inside thirteen block references. Preserve the drawing values as source claims and record the STEP member names and coordinates as separate model observations.

`scripts/small_bms.py` extracts a reusable persistence check from the existing OCS save/reopen workflow. `compare_sat_sab(pre_save_sat, reopened_sab)` uses `step_placements.identity_sat_vertices` and `native_acis.sab_structure` to compare canonical reachable vertex sets, report the reopened shell topology, and retain actual surface types. It accepts the identity `transform` record observed in the C054 SAT and relies on the existing native reader to reject unsupported transforms. The check uses seven-decimal coordinate canonicalization; this is a software comparison threshold, not a manufacturing tolerance.

Supported inputs are a nonempty pre-save ACIS SAT string containing finite point records and no transform other than the supported identity frame, plus nonempty reopened ACIS700 SAB bytes with one reachable body. Coordinates are interpreted in the import job's declared millimetres (`INSUNITS=4` for this case). The seven decimal places are coordinate rounding for persistence comparison, not a dimension tolerance, drawing tolerance, or measurement uncertainty. The actual C054 test suite exercises both a changed point with an unchanged transform (FAIL) and an unsupported changed transform (rejected).

`compare_assembly_instances(...)` uses the existing block traversal to compare instance paths and rigid transforms. `assembly_point_extrema(...)` labels point-coordinate ranges explicitly. Point ranges do not establish extrema of curved surfaces and are not a substitute for an analytic enclosure-envelope measurement.

The actual C054 case test data under `execution/component-followups-2026-11-13/c054/` contains one pre-save sticker solid SAT record and its reopened DWG SAB record. The test passes: 16 unique point coordinates match; the reopened graph reports one body, one lump, one shell, 10 faces, 48 coedges with reciprocal closed partners, and plane/cone surface types. The imported assembly's point ranges are retained in the component report.

The Rev00 drawing labels four `R1.75` slot-end arcs. The nine imported SAT solids contain no analytic cylindrical face with radius 1.75 mm in the inspected `cone-surface` records. The source-specific handoff records this as a geometric feature observation; it does not infer slot geometry from the drawing or from a point-range comparison.
