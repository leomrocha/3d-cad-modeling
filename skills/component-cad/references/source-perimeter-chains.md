# Source-vector perimeter reconstruction

Use this procedure when a technical drawing stores a projected outline as separate vector paths and a source-traced profile reference needs one closed boundary. Keep the source drawing, vector extraction, trace, and constructed profile as separate records.

1. Identify the exact source page and orthographic view. Pin the original drawing and any vector derivative by hash. Record the derivative's coordinate units and the complete transform to millimetres; do not infer scale from a screenshot.
2. Inspect the source view before selecting paths. Select only the outer boundary for the named representation. Exclude internal seams and nearby dimension leaders. Retain the source path, subpath, and segment identifiers for each selected segment. State the indexing convention (including whether IDs are local to a path or global), verify that every ID exists in the pinned derivative, and reproduce each selected segment's transformed endpoints before use. A source index that cannot be resolved is a failed binding, even when the visible contour appears plausible.
3. Split a long source line only at a point where another source-supported boundary joins it. Omit the line portion covered by that boundary; do not close a protrusion with an invented edge.
4. Build an endpoint graph from the selected paths. Require one connected loop with degree two at each joined endpoint. Record every endpoint gap, the join threshold, the join method, and each endpoint's maximum movement. Reject unexplained gaps or branching rather than silently bridging them.
5. Preserve every source vertex that defines the selected trace. Merge only numerically duplicate consecutive vertices under an explicit distance bound; record the maximum merge displacement. Validate the resulting polygon with the existing [profile reference helper](../../../scripts/profile_reference.py) before any native construction.
6. Compute the trace extents from the selected vertices. Compare those extents with independent printed source dimensions, not with values derived from the same polygon. Derive an extent interval from identified tracing uncertainty at both extreme points. Keep that interval separate from native readback precision and any manufacturer tolerance.
7. Record source view, selected path IDs, profile points, frame, extent comparisons, uncertainty arithmetic, and excluded features in the external component job. Preserve alternate representations and the conditions for using them.

An applied source-index check found that a saved pair of labels, `path[35]` subpaths 368 and 370, did not resolve in the pinned C048 SVG: that path has 124 move-started subpaths and 349 commands. The traced profile remained unchanged while its two curved spans were rebound to actual `path[35]` subpaths 101 and 103, cubic segment 1, by transformed-coordinate matching. Keep that failed label and the corrected binding in the component evidence; future jobs use the verified path-local identifiers and endpoint records.

Endpoint closure is a geometric interpretation. A closed-loop validation proves the submitted polygon is connected and simple; it does not prove that the chosen paths represent the complete physical part. A profile extrusion reproduces the recorded 2D trace through its specified depth and does not recover hidden surfaces or dimension undrawn interfaces.
