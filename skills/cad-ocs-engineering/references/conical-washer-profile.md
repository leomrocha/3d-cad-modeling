# Conical washer from a normal-thickness strip

1. **Inputs:** external source job with inside/outside diameters, normal material thickness, free height, exact configuration name, millimetre units, frame and source hashes. Keep post-test and loaded heights as separate source claims.
2. **Drawing interpretation:** inspect diameter and height extension endpoints and the material-thickness direction. The supported section is a rectangular strip inclined in the axial/radial plane. Its revolved faces represent a free nominal washer. Installation orientation and a multi-washer stack are separate component operations.
3. **Calculation:** [conical_washer_profile.py](../scripts/conical_washer_profile.py) solves radial width `w=s*cos(a)+t*sin(a)` and height `H=s*sin(a)+t*cos(a)`, where `s` is strip length, `t` is normal thickness and `a` is inclination. The caller declares a shallow angle interval within 0–45 degrees. The helper isolates polynomial roots and accepts exactly one physical solution satisfying the unsquared equations and `s>t`.
4. **Geometry:** revolve the four section corners with existing `Geometry.revolve_z`; use explicit caller placement and source metadata. Resolve named source roots on a runtime copy of the input.
5. **Validation:** before writes, reject changed source hashes, invalid radii/height/thickness, numerical collapse and ambiguous solutions. Synthetic tests check independent forward projections, thickness distance, perpendicular edges, area and failure paths.
6. **Native checks:** retain raw saved SAB records, enable supported rigid transforms and conical surfaces, and compare four unique axial/radial corner stations, diameter/height bounds, cone angles and axis, surface families, source metadata and one closed connected body. Seam duplicates retain their raw count and are compared by distinct axial/radial position.
7. **Persistence and closure:** bind reads to stable document epochs; compare pre-save and reopened native point sets. Capture views before the final save/reopen when using commands that dirty the drawing. Close only completed owned documents with current saved-file proof.
