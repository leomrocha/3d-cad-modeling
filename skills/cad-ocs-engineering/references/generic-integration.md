# Reusable geometry, recovery and artifact methods

## Runtime and durable progress

1. [runtime.py](../scripts/cadtools/runtime.py): Client/Journal bind requests to document/session, record intents before send, fsync evidence and poll original IDs with max_queries, timeout, poll_interval and recovery_deadline. RecoveringClient preserves the earlier proxy API. owned_document/new_owned_document bind exact NEW/OPEN responses and recover original intents on restart.
2. [records.py](../scripts/cadtools/records.py): iter_records starts at page_size and halves on the 16 MiB transport limit at the same offset. Validate page bounds, unique handles/names, progressing offsets and document/revision/geometry identity. read_stable_entity requires one exact handle and unchanged identity. Audit manifests name native Solid3D and Insert records as 3D Solid and Block Reference. Use audit_type_counts when comparing those record types with the audit. Keep the original audit manifest in the save receipt.
3. [checkpoints.py](../scripts/cadtools/checkpoints.py): write_stage_checkpoint requires caller job identity and an exact stage prefix, serializes writers and fsyncs atomic JSON replacement. save_checkpoint saves a new native DWG at an idle owned epoch, audits the intended output path even when the active document came from DXF, verifies actual bytes/hash/audit/counts and retains IN_PROGRESS. Use a distinct label/path per checkpoint; recover an uncertain save by its original ID. When writing a receipt, supply explicit roots to normalize stored paths; resolve those locators before passing persistence evidence to cleanup. Merge overlapping source lists with `merge_source_pins` before creating an owned document. Identical path/hash pairs collapse in first-seen order. A conflicting hash for the same locator stops preparation. Use consistent locator spelling for each file. Final save/reopen remains a separate operation.

## Geometry construction and checks

[Geometry adapters](../scripts/cadtools/geometry.py) return solid handles directly from `cylinder`, `sphere`, `extrude` and `revolve_z`. Save the resulting handle at the next checkpoint. Use `added(response)` only when extracting a handle from a raw native `run` response. After a caller error, recover the completed operation from its journal and confirm the saved document and resulting handle before issuing another command.

1. [plate_reference.py](../scripts/plate_reference.py): build_plate consumes sketch_bounds, outline, bulges, holes (axis/centre/diameter/span), cutouts, rotations, translation, explicit cutter_overrun_mm and optional metadata. Inputs are mm; rotation angles are degrees. It returns the native body handle. Validate the entire recipe before mutations. verify_plate compares final-frame bounds, hole groups and witness vertices with a supplied tolerance.
2. [planar_profiles.py](../scripts/planar_profiles.py): bounded_extrusion consumes closed line/bulge boundaries, an explicit material-region pickpoint and positive height. It deletes only its retained temporary profiles and identifies one newly created solid. Pass a `checkpoint(stage, handles)` callback when the job requires a checked save after each profile, the identified solid and any temporary-profile deletion. The callback must raise if the save fails or remains uncertain. The helper then leaves the latest completed native stage in place for recovery. clip_circular_openings clips a simple polygon with equal-radius disks, returns exact circular bulges, signed area and outer/opening loop roles, and rejects coincident/ambiguous boundaries. Supply source-specific analytic boundary derivations through the job. For a dense, independently verified clearance projection, `conservative_tool_polygon` uses a caller-supplied polygon engine with Shapely-compatible buffer, simplify and covers operations. Supply the expansion, simplification tolerance, vertex limit and maximum added area. Preserve the original projection and check that the reduced tool contains it before a native cut. Report geometric overcut and keep any through-wall or open-end extension in the caller recipe.
3. [rounded_tube.py](../scripts/rounded_tube.py) already supplies rounded hollow-section validation, quarter-circle profiles and native construction. [cut_sidewalls](../scripts/plate_reference.py) takes explicit nonoverlapping material intervals and cuts each wall separately. The caller supplies cavity-equivalence reasoning and expected source geometry. The hollow-section solid-subtract route requires an explicit construction.cutter_overrun_mm value before any native write.
4. [feature_checks.py](../scripts/feature_checks.py) compares finite observations, deduplicated projected cylinder axes and actual cylinder-face wall endpoints. [native_acis.py](../scripts/native_acis.py) keeps strict SAB feature decoding by default. The SAT readback reports reachable vertices and faces, reciprocal coedge links to the same edge, and straight or elliptical trim geometry. Explicit rigid transforms are opt-in. For a documented chamfer adjoining a cylindrical bore, use `sab_features(..., allow_cones=True)` and read the cylindrical section from `cylinders`. Check chamfers and finite engagement as their own observations. When a strict read stops on a known chamfer, verify the live handles and saved checkpoint before retrying readback with the cone option. Unsupported trim equations retain their endpoints.
5. [native_geometry.py](../scripts/native_geometry.py) selects SAB or supported identity-frame SAT features, reads stable native identities, transforms lightweight-polyline OCS vertices to WCS, reads straight centreline segments from explicit zero bulges and the native is_closed flag, and aggregates observed assembly vertices with explicit scale/reflection mode. Unsupported surface/layout errors retain original bytes for inspection.
6. [source_vector_paths.py](../scripts/source_vector_paths.py) parses the explicit SVG M/L/C/Z grammar with path/subpath/segment IDs. It applies caller six-term affine matrices, positive unit conversion and signed Y mapping. Cubic evaluation and segment distance keep source chain selection and uncertainty outside the helper.

## Assemblies and native views

1. [step_placements.py](../scripts/step_placements.py) composes native source placements. Unit reflection is opt-in. classify_hand validates a finite orthonormal affine matrix; nested reflection parity follows composed matrices. Array inserts and nonzero block bases retain explicit errors.
2. [assembly_build.py](../scripts/assembly_build.py) implements the inspected -INSERT prompts, stamps source locator/hash and verifies native metadata and placement. Supply portable source_locator, point mm and unit yscale. verify_child_placements checks saved instance matrices and exact metadata.
3. [assembly_occurrences.py](../scripts/assembly_occurrences.py) expands caller group records into inserted leaf-part quantities and matrices. Each child needs name/source/source_sha256 and matrix or point/yscale. A nested group SHA must match the inserted source revision. It retains mirrored hands, repeated occurrences, a maximum occurrence count and explicit cycle/depth rejection. recover_insert_sequence consumes the declared insertion journal protocol and rejects incomplete/conflicting terminal results. write_occurrence_tables emits protected parts/instance TSV files, reads every field back and records file hashes; supply roots when normalizing runtime part paths for storage.
4. [native_views.py](../scripts/native_views.py) traverses native SAT and SAB boundaries and straight polyline centrelines under actual nested unit-scale/mirrored placements. Straight edges use native endpoints; ellipses use native parameters and sampling; unsupported nonlinear trims display endpoint dots. render_views emits XY/XZ/YZ and isometric SVG/PNG with hashes. render_saved_model binds exact OPEN identity, reads stable pages, checks source hash and closes its owned view document. Supply the passing source persistence receipt, a fresh stem/output directory and a coordinated native interval. Extents describe displayed samples/endpoints. Set `include_xy_circles=True` for zero-thickness native circles with +Z local normals, such as bolt-hole and sweep datums. Circle samples follow each recorded nested placement, including unit reflection. Use native centres and radii for dimensional checks.
5. For exact axis-aligned placements, compare independently measured local bounds and intended installation bounds with `check_axis_aligned_placement` before native edits. It applies the full signed axis permutation and translation to the source corners. A reversed axis changes which corner anchors the minimum face. After placement, still check live occurrence transforms and geometry.
6. For a single top-level solid after a Boolean, the native model-space membership list can retain erased tool handles. Verify the exact saved checkpoint, live geometry revision and sole expected solid handle. Pass that stable live inventory to `single_solid_boundary_edges` to render the checked body directly. Use `placed_boundaries` for groups and assemblies so a missing instance remains a verification error.
7. [ocs_document_cleanup.py](../scripts/ocs_document_cleanup.py) closes exact owned completed documents using saved hash and epoch evidence. Inactive clean close requires explicit installed support and an exclusive interval because revision guards bind the active tab. [Full cleanup contract](document-cleanup.md).

## Retained relationships

[retained_artifacts.py](../scripts/retained_artifacts.py) validates portable file/hash manifests and optional relationships. Each binding names a registered record, registered artifact and JSON-pointer field containing that artifact's digest, for example {"record":"view.json","artifact":"model.dwg","field":"/source_sha256"}. It rejects stale model/image/table links even when each current file has an individually correct hash. Keep insertion-time and currently observed source hashes as separate fields.

All methods accept caller-owned source/model/job data. Retain units, frames, prerequisites, inputs/outputs, actual checks, failed operations and downstream conditions with the job. The package carries code and procedures; it carries synthetic examples rather than another project's models or execution files.

Use `revolve_profile_y` in [planar_profiles.py](../scripts/planar_profiles.py) for a full revolution of an owned XY radial section about Y. Supply a verified `checkpoint(stage, handles)` callback to save the section, new solid and any retained-section deletion. A failed save stops further geometry changes. The caller supplies validation of the radial section, units, final pose, source dimensions and closure.

For a sketch consumed by native REVOLVE, use `model_space_after_revolve` from `cadtools.records`. Supply the original request, completed response, source sketch handle, generated solid handle and current inventory. The exact Removed and Added evidence permits the stale sketch reference only when the sketch is absent from the current inventory. Keep explicit deletions on `model_space_live_handles`.

For positive-WCS-Z XY polylines with native bulges, use `xy_polyline_view_curves` or opt into `placed_boundaries(..., include_xy_bulges=True)`. The curve points follow signed native arcs and the native closure flag. Keep the observed bulges and source dimensions as separate exact geometry checks.

For a countersink above a cleared bore, use `countersink_tool_profile` to derive the annular revolve profile and axial depth. Supply the bore, mouth, included angle, inner radius and axial overrun. Read text ACIS cones with `sat_readback(..., include_cones=True)` and binary cones with `sab_features(..., allow_cones=True)`. Compare bore patterns by unique coincident axes and verify the native cone and rim stations separately.

Use `bounded_wall_in_empty_document` when the owned hollow-section build requires incremental saves. Its callback receives the profiles, new hollow solid with any retained profiles, and finally the solid after owned profile cleanup. Verify each checkpoint before the helper proceeds. The caller owns units, final placement, source checking and closure.

### Build a constant-thickness quarter bend

Use `quarter_bend_section` in [planar_profiles.py](../scripts/planar_profiles.py) for a finished sheet section with concentric 90° inner and outer arcs. Supply the bend centre, inside radius, thickness and both tangent-to-end straight lengths. It returns a lower-left quarter bend with one upright leg and one rightward leg. Extrude the section along the part's longitudinal axis. Verify the native arc radii and centre, both ends of each straight leg and the installed bearing planes before cutting holes. Sheet development uses the selected process allowance and has separate inputs.

Use `reframe_planar_profile` to map a closed outline into another cardinal section frame before extrusion. Supply the new origin and the signed direction of each source axis. A proper rotation preserves arc bulge signs. A reflection reverses the signs while preserving the vertex and edge order. Check the corresponding native tangent endpoints and radii in the destination frame. A later proper rotation of the full solid, such as reusing the opposite installation of one angle, preserves its definition and uses a separate occurrence transform.

For an offset bracket with two opposing quarter bends, use `offset_bend_section`. Supply the lower bend centre, one common inside radius and thickness, the tangent-to-tangent web length, and each straight leg length. The vertical offset between bend centres is the sum of the inner and outer radii. Compare both pairs of cylindrical bend surfaces and all tangent stations. If the equal formed section receives opposing hole offsets, record separate drilled variants and verify each mating pattern.

### Form a perforated web before joining its flanges

Use this route when a native Boolean refuses to cut an otherwise valid formed section. Verify that the failed request changed no handles or geometry revision. Preserve its checkpoint and use a new operation identity for the alternative construction.

1. Identify a planar web with constant thickness and source-defined openings that leave the flange joins intact. Place each join inside unperforated web material and specify a positive overlap. Keep both members within the intended material on the overlap.
2. Form the web with `bounded_extrusion` from its outer profile and all opening loops. Use an explicit material pick point. For round-ended openings, reuse `round_ended_slot_profile` and preserve the bulge signs under proper planar rotations. Save the checked web before adding flanges.
3. Extrude each flange from the source section with its bend arcs and a small overlap into the web. Save after extrusion and after placing it in the common frame. Unite the solids using `Geometry.combine`. Save and read back the result as one closed, connected lump. Compare both section ends, the cylindrical bend radii, and the two rims and arc centres of every opening to the source-bound recipe. Preserve the intermediate solids if the union or any readback fails.

### Recover a flat plate with mixed round bores and slots

When a solid subtraction rejects a round-ended slot, verify the failed request changed no geometry and pin the latest checkpoint before removing the owned trial solids. Form the plate from its outer loop and slot loops with `bounded_extrusion`, using a pick point in known retained material. Round through-bores can be included as verified closed loops or added using separately qualified cylinder cuts. Checkpoint each completed stage. After placement, compare the distinct slot-end cylinder axes and radii against the input. Use `round_ended_slot_tangents` in [feature_checks.py](../scripts/feature_checks.py) to match the two native straight connecting edges on each sheet face. It takes the boundary records, axis, two planar end centres, radius, face stations and tolerance. For each slot rim, check the outward semicircle at each end centre. Bind its two tangent endpoints, radial samples in the outward half-plane and a sample near the extreme length station. An arc with matching endpoints supplies only endpoint evidence. The full-ring sample check requires all four quadrants and applies to complete circular rims. For split collinear edges, review continuous coverage independently. Verify both face stations and the closed final solid.

Pass the verified first occurrence as `previous` to `insert_component` to reuse the same native block definition. Compare the pinned source hash, locator and metadata. Pass the same first occurrence to `recover_insert_component` when the repeated insertion response needs recovery, so the original block token and request identity are checked.

## Compare straight boundaries after import

Read the native Insert's local matrix from its own record. A traversal can report the parent frame at an Insert path and the composed matrix at its physical children. Verify the local placement and use the composed child matrix for the world-space geometry check.

When supported solids have different native payloads after import, check matching dimensions, independent placement and boundary geometry. For straight, axis-aligned native boundaries, apply `axis_aligned_edge_coverage` from [feature_checks.py](../scripts/feature_checks.py) to the source and mounted endpoint pairs in the same frame. Use a declared coordinate precision. The comparison merges split or overlapping segments on each supporting line and retains gaps. Extra planar seam edges require separate checking against the intended face. Curved or diagonal boundaries require their appropriate feature reader. Check face shape, solid topology and material separately where the job requires them.

## Carry display roles between operating poses

Use the checked functional palette as a source for the role names and colours. Pin the alternate-pose drawing and its own geometry receipt. Read the alternate pose's physical occurrences and recover each role from its own native metadata or construction record. Hardware and reference occurrences can differ between poses. Derive each assignment from the role and check the actual occurrence count before styling.

When reusing an existing fitted linkage with a current catalogue tool, compare the active model-space roots to the known base and isolate the exact lift, joint hardware and tool. Verify which joint pieces the catalogue tool supplies. Retain only the complementary hardware. Check the tool and linkage separately in the assembled frame before screening their contact and service paths. Keep the catalogue source unchanged.

Apply assignments to the owned derivative. Check every affected occurrence of each edited definition, including shared definitions. Verify geometry, transforms, membership and hidden references independently of the display changes. Report layer counts for the actual pose and save the matching native view.
