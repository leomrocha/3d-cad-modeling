# Reusable geometry, recovery and artifact methods

## Runtime and durable progress

1. [runtime.py](../scripts/cadtools/runtime.py): Client/Journal bind requests to document/session, record intents before send, fsync evidence and poll original IDs with max_queries, timeout, poll_interval and recovery_deadline. RecoveringClient preserves the earlier proxy API. owned_document/new_owned_document bind exact NEW/OPEN responses and recover original intents on restart.
2. [records.py](../scripts/cadtools/records.py): iter_records starts at page_size and halves on the 16 MiB transport limit at the same offset. Validate page bounds, unique handles/names, progressing offsets and document/revision/geometry identity. read_stable_entity requires one exact handle and unchanged identity.
3. [checkpoints.py](../scripts/cadtools/checkpoints.py): write_stage_checkpoint requires caller job identity and an exact stage prefix, serializes writers and fsyncs atomic JSON replacement. save_checkpoint saves a new native DWG at an idle owned epoch, audits the intended output path even when the active document came from DXF, verifies actual bytes/hash/audit/counts and retains IN_PROGRESS. Use a distinct label/path per checkpoint; recover an uncertain save by its original ID. When writing a receipt, supply explicit roots to normalize stored paths; resolve those locators before passing persistence evidence to cleanup. Final save/reopen remains a separate operation.

## Geometry construction and checks

1. [plate_reference.py](../scripts/plate_reference.py): build_plate consumes sketch_bounds, outline, bulges, holes (axis/centre/diameter/span), cutouts, rotations, translation, explicit cutter_overrun_mm and optional metadata. Inputs are mm; rotation angles are degrees. It returns the native body handle. Validate the entire recipe before mutations. verify_plate compares final-frame bounds, hole groups and witness vertices with a supplied tolerance.
2. [planar_profiles.py](../scripts/planar_profiles.py): bounded_extrusion consumes closed line/bulge boundaries, an explicit material-region pickpoint and positive height. It deletes only its retained temporary profiles and identifies one newly created solid. clip_circular_openings clips a simple polygon with equal-radius disks, returns exact circular bulges, signed area and outer/opening loop roles, and rejects coincident/ambiguous boundaries. Supply source-specific analytic boundary derivations through the job.
3. [rounded_tube.py](../scripts/rounded_tube.py) already supplies rounded hollow-section validation, quarter-circle profiles and native construction. [cut_sidewalls](../scripts/plate_reference.py) takes explicit nonoverlapping material intervals and cuts each wall separately. The caller supplies cavity-equivalence reasoning and expected source geometry. The hollow-section solid-subtract route requires an explicit construction.cutter_overrun_mm value before any native write.
4. [feature_checks.py](../scripts/feature_checks.py) compares finite observations, deduplicated projected cylinder axes and actual cylinder-face wall endpoints. [native_acis.py](../scripts/native_acis.py) keeps strict boundary decoding by default; edge_policy=endpoints explicitly retains unsupported trim endpoint evidence for wall checks.
5. [native_geometry.py](../scripts/native_geometry.py) selects SAB or supported identity-frame SAT features, reads stable native identities, transforms lightweight-polyline OCS vertices to WCS and aggregates observed assembly vertices with explicit scale/reflection mode. Unsupported surface/layout errors retain original bytes for inspection.
6. [source_vector_paths.py](../scripts/source_vector_paths.py) parses the explicit SVG M/L/C/Z grammar with path/subpath/segment IDs. It applies caller six-term affine matrices, positive unit conversion and signed Y mapping. Cubic evaluation and segment distance keep source chain selection and uncertainty outside the helper.

## Assemblies and native views

1. [step_placements.py](../scripts/step_placements.py) composes native source placements. Unit reflection is opt-in. classify_hand validates a finite orthonormal affine matrix; nested reflection parity follows composed matrices. Array inserts and nonzero block bases retain explicit errors.
2. [assembly_build.py](../scripts/assembly_build.py) implements the inspected -INSERT prompts, stamps source locator/hash and verifies native metadata and placement. Supply portable source_locator, point mm and unit yscale. verify_child_placements checks saved instance matrices and exact metadata.
3. [assembly_occurrences.py](../scripts/assembly_occurrences.py) expands caller group records into inserted leaf-part quantities and matrices. Each child needs name/source/source_sha256 and matrix or point/yscale. A nested group SHA must match the inserted source revision. It retains mirrored hands, repeated occurrences, a maximum occurrence count and explicit cycle/depth rejection. recover_insert_sequence consumes the declared insertion journal protocol and rejects incomplete/conflicting terminal results. write_occurrence_tables emits protected parts/instance TSV files, reads every field back and records file hashes; supply roots when normalizing runtime part paths for storage.
4. [native_views.py](../scripts/native_views.py) traverses saved SAB boundaries under actual nested unit-scale/mirrored placements. Straight edges use native endpoints; ellipses use native parameters and sampling; unsupported nonlinear trims display endpoint dots. render_views emits XY/XZ/YZ and isometric SVG/PNG with hashes. render_saved_model binds exact OPEN identity, reads stable pages, checks source hash and closes its owned view document. Supply the passing source persistence receipt, a fresh stem/output directory and a coordinated native interval. Extents describe displayed samples/endpoints.
5. [ocs_document_cleanup.py](../scripts/ocs_document_cleanup.py) closes exact owned completed documents using saved hash and epoch evidence. Inactive clean close requires explicit installed support and an exclusive interval because revision guards bind the active tab. [Full cleanup contract](document-cleanup.md).

## Retained relationships

[retained_artifacts.py](../scripts/retained_artifacts.py) validates portable file/hash manifests and optional relationships. Each binding names a registered record, registered artifact and JSON-pointer field containing that artifact's digest, for example {"record":"view.json","artifact":"model.dwg","field":"/source_sha256"}. It rejects stale model/image/table links even when each current file has an individually correct hash. Keep insertion-time and currently observed source hashes as separate fields.

All methods accept caller-owned source/model/job data. Retain units, frames, prerequisites, inputs/outputs, actual checks, failed operations and downstream conditions with the job. The package carries code and procedures; it carries synthetic examples rather than another project's models or execution files.
