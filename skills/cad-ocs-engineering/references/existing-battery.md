# Read and check an existing shell-and-terminal component

1. Reconcile the existing model, exact source variant, required representation and saved checks. Bind each shell, mounting, wall and terminal expectation to supplied source bytes, units/frame, hash and evidence label.
2. Open the saved model through the guarded runtime with explicit session/namespace and exact response identity. Preserve original file bytes and unrelated documents. Recover uncertain requests by their existing identity.
3. [native_acis.named_parts](../scripts/native_acis.py) resolves the caller's metadata application, required part names and optional aliases. Reject duplicate or missing names; enable supported transforms explicitly.
4. [battery_module.check](../scripts/battery_module.py) compares caller-bound shell extrema, mounting cylinders, inner wall planes and terminal contact/bore geometry for its supported shell/terminal family. Use actual body topology and the supplied numerical threshold. Keep reconstructed features separately attributed.
5. Compare saved file hashes, expected entity counts, metadata and source-bound geometry. A requested revision receives its own derivative and incremental checkpoints.
6. Inspect top, interface and isometric views from the same model. Record actual image identity and source/model hashes with caller-owned results.
