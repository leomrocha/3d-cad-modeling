# Evidence and installed capabilities

1. Inspect the selected native session's state, capabilities, command manifests and record schemas before unfamiliar operations. Keep software version and observed capability results with the caller's job.
2. Label implemented code, automated synthetic tests, executed native operations, saved/reopened checks and inspected pixels separately. A declared API capability supplies its schema; the completed response and readback supply execution evidence.
3. Pin source bytes with title, origin, observation date, units, frame and hash in caller-owned job records. Preserve originals and label inferred values and proposals explicitly.
4. Review concrete errors and supported representation boundaries using the bundled [native runtime](ocs-runtime.md), [geometry methods](generic-integration.md) and [metadata checks](source-metadata.md).
