# Source-bound hexagonal reference geometry

Use `scripts/hexagonal_reference.py` when an external component job supplies a regular hexagonal across-flats dimension and axial height. The helper creates one six-sided prism reference with the caller's placement frame. A caller may add a source-dimensioned coaxial through-bore by binding a required diameter feature; a nominal thread designation by itself remains axis metadata.

The job binds `dimension_features.across_flats` and `dimension_features.height` to unique required source features. An optional `dimension_features.bore_diameter` binds a third required source feature and requires a positive `construction.cutter_overrun_mm`. Each numeric source feature needs `value`, `unit: "mm"`, `required: true`, `source`, `source_sha256`, `source_location`, and `evidence_status`. The job also supplies pinned `source_files` with a runtime `path`, a portable `locator`, and a SHA-256, `units: "mm"`, a readable `representation`, `geometry_role: "reference_hexagonal_prism"`, `metadata_application: "CADTOOLS_SOURCE"`, and explicit identity and metadata request labels. XData stores the portable locator and hash, while source-byte validation uses the resolved runtime path.

The `placement` object has `origin`, `axis`, and `radial_x`. `origin` is the centre of the lower axial face. `axis` and `radial_x` are unit vectors and perpendicular; the helper derives local `radial_y = axis × radial_x`, which completes a right-handed frame. The extrusion runs from the origin along the supplied axis. Existing `Geometry` methods orient the local solid with cardinal-axis rotations and then move it to the supplied origin.

`regular_hexagon_points(across_flats_mm, center=(0, 0), rotation_degrees=0)` returns six counterclockwise XY vertices. `parameters(job)` checks source readiness, dimensions, frame, all generated profile coordinates, bore radius/overrun, source hashes and metadata before native writes. `build_hexagonal_reference(client, job)` returns the resulting solid handle. `verify(features, job)` deduplicates coincident surface patches, then requires exactly six source-matched side planes and two cap planes, the optional coaxial bore cylinder, no extra analytic cylinders/cones/spheres, and one closed connected body. A through-bore also requires an inner boundary loop at both cap stations. `verify_metadata(record, handle, job)` compares ordered `CADTOOLS_SOURCE` strings. `inspect(client, handles, job)` reads one native `Solid3D` SAB record and requires the record response and before/after state to match the same active document, revision, and geometry revision.

Use a representation label such as “maximum-dimension hexagonal clearance reference” when source values are limits and the helper constructs the limit values. The prism fills its full axial height at the supplied across-flats dimension; chamfers, raised collars, rounded transitions, insert shapes, wrench-access clearances and helical threads are outside the representation unless separately sourced and modeled. Keep nominal thread axes and pitches in metadata when their physical bore profile is not sourced.

The generic utility and its tests exercise numeric profile generation, source-job validation, arbitrary right-handed frame calculations, native API call planning, analytic-feature checks and metadata comparison with synthetic inputs. Those tests do not establish an OCS build result; retain actual saved-document and source-feature checks in the owning component case.
