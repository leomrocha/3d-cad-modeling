# Bundled OpenCADStudio runtime

1. **Software:** Python 3.12 on Linux or macOS, the pinned packages in [requirements.txt](../requirements.txt), and an already-running OpenCADStudio native-control session. The transport uses a local TCP socket and the existing session descriptor. It reads the session's authentication token privately.
2. **Code:** [ocs_control.py](../scripts/ocs_control.py) provides discovery, read requests and guarded execution. [runtime.py](../scripts/cadtools/runtime.py) provides `Client`, `Journal`, `CadError`, `Uncertain` and explicit `load_helper`. [geometry.py](../scripts/cadtools/geometry.py) provides profiles, transforms, cylinders, extrusion, revolution, Boolean commands and source metadata. [verification.py](../scripts/cadtools/verification.py) provides audit and save/reopen checks. These files accompany this skill installation.
3. **Inputs:** select the existing session with `--session SESSION` or `--descriptor DESCRIPTOR_JSON`. Supply the component job, source revisions, output locations, named roots, journal location, document ID and request namespace. Keep descriptors and tokens out of reports. Resolve job roots as described in [paths.md](paths.md).
4. **Read first:** use `python "$SKILL_ROOT/scripts/ocs_control.py" read --session SESSION --request '{"op":"state"}'`. Inspect capabilities, document identity, geometry revision, header units and current contents. Inspect the installed command and record schemas before unfamiliar operations.
5. **Model contract:** record source dimensions with evidence labels, units, origin, right-handed axes, datums, separate component names and interfaces. Keep appearance properties separate from physical material inputs. Existing documents and sources remain caller-owned.
6. **Authorized edits:** create one `Client` per selected document with `allow_write=True` only for the authorized job. Use an append-only `Journal` and stable request IDs. The bundled client binds a mutation to the observed document and revision. `SelectionCheckedClient` in [rounded_tube.py](../scripts/rounded_tube.py) corrects the installed clear-only selection behavior and checks selected handles.
7. **Recovery:** after an uncertain response, call `Client.recover()` with the original request ID and journal. Record actual operation status and any committed earlier steps. Inspect stale-state rejections before reconsidering the edit.
8. **Checks:** bind native records to the intended document and geometry revision, compare supported features with independently sourced expectations, and inspect captured component identity. [check_contract.py](../scripts/check_contract.py) checks caller-supplied points, axes and planes; [model-contract.md](model-contract.md) describes its JSON input. A screenshot supplies visual evidence; source-bound geometry checks supply dimensional evidence.
9. **Persistence and handoff:** `save_reopen(client, new_absolute_dwg_path, expected_counts)` audits the target, verifies the saved hash and manifest, reopens the model and checks the audit again. Inspect reopened geometry and source metadata separately. Close completed owned documents using the [cleanup procedure](document-cleanup.md). Store model, journal, checks and cleanup receipt in the component project.
10. **Dependency check:** `python "$SKILL_ROOT/scripts/package_check.py"` checks installed files, imports, dependency versions and the SAB reader. Add `--session SESSION` or `--descriptor DESCRIPTOR_JSON` to read the actual OCS state with zero geometry mutations.
