# Bundled OpenCADStudio runtime

1. **Software:** Python 3.12 on Linux or macOS, the pinned packages in [requirements.txt](../requirements.txt), and an already-running OpenCADStudio native-control session. The transport uses a local TCP socket and the existing session descriptor. It reads the session's authentication token privately.
2. **Code:** [ocs_control.py](../scripts/ocs_control.py) provides discovery, read requests and guarded execution. [runtime.py](../scripts/cadtools/runtime.py) provides `Client`, `Journal`, `CadError`, `Uncertain` and explicit `load_helper`. [geometry.py](../scripts/cadtools/geometry.py) provides profiles, transforms, cylinders, extrusion, revolution, Boolean commands and source metadata. [verification.py](../scripts/cadtools/verification.py) provides audit and save/reopen checks. These files accompany this skill installation.
3. **Inputs:** select the existing session with `--session SESSION` or `--descriptor DESCRIPTOR_JSON`. Supply the component job, source revisions, output locations, journal location, document ID and request namespace. Keep descriptors and tokens out of reports. Resolve selected job paths as described in [paths.md](paths.md).
4. **Read first:** use `python "$SKILL_ROOT/scripts/ocs_control.py" read --session SESSION --request '{"op":"state"}'`. Inspect capabilities, document identity, geometry revision, header units and current contents. Inspect the installed command and record schemas before unfamiliar operations.
5. **Model contract:** record source dimensions with evidence labels, units, origin, right-handed axes, datums, separate component names and interfaces. Keep appearance properties separate from physical material inputs. Existing documents and sources remain caller-owned.
6. **Authorized edits:** create one `Client` per selected document with `allow_write=True` only for the authorized job. Use an append-only `Journal` and stable request IDs. The bundled client binds a mutation to the observed document and revision. Before launching an owned session or opening an owned document, check two independent UTF-8 byte limits. The client namespace must be 1–64 bytes. Each full request ID must be at most 128 bytes, including the namespace, colon, operation label and generated suffixes. Choose a short, deterministic namespace tied to the pinned job inputs and record it with the journal. Preflight the planned labels with their longest generated suffixes. Keep descriptive component names in metadata and receipts. `SelectionCheckedClient` in [rounded_tube.py](../scripts/rounded_tube.py) corrects the installed clear-only selection behavior and checks selected handles.
7. **Recovery:** after an uncertain response, call `Client.recover()` with the original request ID and journal. Retain the recorded namespace when recovering journaled operations. Record actual operation status and any committed earlier steps. Inspect stale-state rejections before reconsidering the edit.
8. **Checks:** bind native records to the intended document and geometry revision, compare supported features with independently sourced expectations, and inspect captured component identity. [check_contract.py](../scripts/check_contract.py) checks caller-supplied points, axes and planes; [model-contract.md](model-contract.md) describes its JSON input. A screenshot supplies visual evidence; source-bound geometry checks supply dimensional evidence. Measure the final geometry in the owned active document when the job needs save confirmation only. Bind the measurements to the saved geometry revision and confirm the persisted save receipt, exact path and file hash. Open the saved file when a later edit, source read or native view requires it, or when the job explicitly calls for a save/load check.
9. **Persistence and handoff:** follow [Save work in progress](../SKILL.md#save-work-in-progress) throughout construction and revision, retaining verified native checkpoints and supporting files with IN_PROGRESS status. `save_reopen(client, new_absolute_dwg_path, expected_counts)` audits a new target, verifies the saved hash and manifest, reopens the model and checks the audit again. Inspect reopened geometry and source metadata separately. Close completed owned documents using the [cleanup procedure](document-cleanup.md). Store model, journal, checks and cleanup receipt in caller-owned job storage. Reserve distinct labels for construction and saves within one client namespace. For example, use a stable `checkpoint-` prefix for saved stages. A previously journaled save label can recover only the same path and geometry revision.
10. **Dependency check:** `python "$SKILL_ROOT/scripts/package_check.py"` checks installed files, imports, dependency versions and the SAB reader. Add `--session SESSION` or `--descriptor DESCRIPTOR_JSON` to read the actual OCS state with zero geometry mutations.

For calculated geometry arguments, convert validated array-library scalars and vectors to ordinary finite Python numbers and lists at the CAD call boundary. Preserve the coordinate frame, units and tolerance during conversion. Check calculated profiles, cutter dimensions, rotation axes and translation vectors before a long native build.

## Preflight native recipe imports

Run the import and helper-resolution code for the selected native action with the intended Python interpreter and dependency paths. Use a job-owned dry-run path that calls the same loader as the native action and stops before it starts a process, connects to OpenCADStudio or opens a document. Check each resolved helper's file path against the pinned source. A planning command that skips native-only imports leaves that part of the preflight unchecked.

When loading a legacy recipe with `runpy.run_path()`, resolve its bare sibling imports explicitly. Keep this adaptation in the job-owned wrapper. Prefer an isolated Python process for recipes with conflicting helper names. If loading them in the same process, scope changes to `sys.path` and the affected `sys.modules` entries to the recipe invocation, including any deferred imports. Restore the prior bindings and remove temporary sibling bindings on exit, including on failure.
