2. **Bind geometry inputs:** the caller supplies source/hash/location for each dimension, mm units, the local frame, representation and cutting overrun. `parameters(job)` checks source readiness, positive finite values and supported shaft/keyway extents before construction. Use separate evidence labels for drawing dimensions and construction choices.
3. **Construct the stationary interfaces:** `housing(client,job)` makes a main cylinder and locating pilot, unions them, and cuts each mounting group from its own front face to its exact blind bottom. The existing guarded `Geometry` and `SelectionCheckedClient` perform the native operations. Nominal thread cylinders retain the drawing's thread designation in the job review.
4. **Construct the rotating interface:** `shaft(client,job)` cuts the blind end-thread cylinder and open-ended keyway. The local profile is extruded radially and rotated into the shaft frame. The rounded inner end uses half the keyway width as its reconstruction radius. For the ME0907, the source width and 36 mm axial extent yield a reconstructed R2.39 mm end; the source does not label that radius independently. `rear(client,job)` constructs the source dimensioned rear reference region as a separate solid.
5. **Read actual geometry:** `inspect(client,handles,job)` uses the existing SAT/SAB readers. `verify(features,job)` checks analytic cylinder radii and axis centres, individual mounting-hole bottom planes, shaft and housing end planes, keyway side/floor planes and rounded-end station. Saved SAB checks also verify each body's closed connected topology. Numerical comparison threshold is 1e-7 mm; source manufacturing tolerances remain separate records.
6. **Choose the right dimension observation:** a complete cylinder can have a single seam vertex. In the executed rear region, both vertices have X=82 mm although the surface diameter is 164 mm. Read radius from the cylinder equation and length from axial planes. Vertex minima/maxima alone would report a zero transverse span.

Verify the saved hash, reopened manifest and source-bound features. The ME0907 case recovered `c005-me0907-build-01:reopen`; geometry was preserved.
8. **Inspect model views and record the actual detail level:** the current saved case contains stationary housing/pilot, keyed shaft and rear reference region.
