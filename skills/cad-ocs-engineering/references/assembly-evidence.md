# Reconstruct and check a sourced assembly

## Manufacturer subsets and repeat occurrences

1. Bind each source occurrence to its selected body, definition, parent path, original length unit and local-to-parent matrix. The same definition may occur on both hands or carry different placements. For isolated subsets, preserve the original product graph and every dependency of each selected body. Inspect reachable entity references with the [STEP entity graph](../scripts/step_entity_graph.py) for one unparameterized DATA section containing simple entity instances. Its ordered graph digest preserves shared references, cycles, string values and numeric spellings while ignoring original ID numbers, whitespace, comments and declaration order. Complex instances, schema semantics and translation-equivalent geometry need separate checks. Root the selection at the required representation and context records. Preserve source units, placements and unmodified payloads when creating any derivative. Check source body and occurrence counts independently with [STEP inventory](step-solid-inventory.md).
2. Reconstruct the placement in the original assembly frame. Where two parts were localized separately, compose target-from-source with the inverse of moving-from-source. Verify named points by independently mapping back through the source frame, then round-trip them. Compare placed vertices, oriented curves and adjacency when repeated bodies have the same vertex set. A changed graph or altered trim remains a separate comparison even when extrema and vertex counts match.
3. For shafts, pivots, spacers and tracks, compare axis direction allowing opposite parameterization, point-to-axis distance, bore radius and signed face stations. Establish finite axial overlap from trimmed material. A mouth circle and shaft tip locate two features. Engagement length requires trimmed bearing surfaces on both parts. Check each declared hand.
4. Use the [assembly occurrence procedure](manufacturer-assembly.md) when replacing a child revision. Record exact parent and child hashes, transforms, quantity, absolute bounds and exported views. Check each affected assembly. For upright top views, set `include_top_isometric=True` in the [native boundary renderer](../scripts/native_views.py) and retain the recorded projection label when comparing revisions. Attribution of populated hardware, source-only features, substituted envelopes and hidden regions travels with the occurrence.

For opposite hands, pass measured world points, a common reference origin and each hand's positive outward unit direction to `directed_axial_span` in [assembly_verification.py](../scripts/assembly_verification.py). Compare the resulting ordered stations against the independent shaft, insert and spacer datums with their signed direction preserved. The returned endpoints describe the observed points. Curved extrema require their own analytic or conservative bounds.

### Verify a changed native INSERT

Read the source feature in its own frame before deriving the new placement. For an axisymmetric part, use two ordered stations on its shaft or bore to check the axis direction. Use a separate off-axis feature, such as a keyway or asymmetric hole, to check clocking when that rotation matters.

For an OpenCADStudio block reference, use [step_placements.py](../scripts/step_placements.py) to encode the proposed local matrix with `native_fields` and decode the live native fields with `native_matrix`. The insertion point is stored in the object coordinate system. A rotation value alone turns about the current insert normal. For a changed axis, update the normal, rotation and insertion point together. Compose the decoded matrix with every parent transform before checking world placement. Convert a desired world pose back to the parent frame before encoding it.

Check the walker's frame contract for the exact occurrence path. A traversal can attach the incoming parent-to-world matrix to an INSERT row and pass the composed matrix to its descendants. Check the definition base point at every nesting level. This reader requires a zero base point. For a nonzero base point, select a reader that maps the definition base point to the insertion point before composing parent transforms. Use `native_fields` for proper rigid transforms (rotation and translation). For the zero-base-point contract, the INSERT world matrix is `multiply(incoming_parent_to_world, native_matrix(insert_properties))`. An identity incoming matrix at a model-space root can accompany a moved or rotated INSERT. A traversal that already returns the INSERT's composed frame uses that frame directly. Use a nonidentity INSERT in a fixture to check the convention before comparing matrices. Record the incoming, decoded local and composed matrices separately when diagnosing a placement mismatch.

Compare the full world matrix with the independently specified pose. Check the origin and basis directions, including scale and handedness. Measure the resulting world-space shaft stations and off-axis feature from the actual child solid. Agreement between the encoder and decoder checks the field conversion. Agreement with source-derived feature positions checks the installed part. Translation and aggregate bounds can agree when a symmetric part points along the wrong axis.

## Fit datums over retained solids

Use a separate native assembly when a fit study needs layout geometry over an existing checked assembly. Insert the checked source at the reviewed transform, then bind its live root handle and compare the descendant solid count with the source. Save the insertion checkpoint before creating the layout geometry.

Put measured source axes, proposed axes and each calculated pose on separate named layers. Represent positions with explicit endpoints in the drawing frame and state which physical feature each endpoint identifies. For example, a shoulder station and the centre of a bearing eye can lie on the same axis at different positions. Keep the two points distinct when the axial offset affects a link length. A line between proposed datums represents a length calculation and has no physical solid.

Read back the native line handles, endpoints and layers independently after creation. Recalculate the required lengths and spans from those endpoints. Confirm the reference lines are at model-space root and the retained solids still descend from the original insert. Validate the saved revision with the caller's persistence method. Report the checked poses and identify any proposed change that requires a new physical part.

## Image constraints

A calibrated in-plane trace requires coplanarity with its reference. For perspective constraints on parallel edges, pin the photo, camera matrix, frame, vanishing point, pixel picks and pick tolerance. Use [photo_constraints.py](../scripts/photo_constraints.py) to intersect line directions consistent with every pick disk. An empty interval rejects that common direction for the supplied camera. Back-project each feasible line to its world plane. Evaluate a metric section only at an independently established depth or height. A direction and small image residual alone leave a family of possible placements.

## Interfaces, installation and contact

1. For a board with multiple apertures, assign distinct openings to its holes and screen invariant pairwise centre distances against enclosing radii and the stated tolerance. [mounting_pattern.py](../scripts/mounting_pattern.py) enumerates assignments up to an explicit budget. A surviving assignment still needs a rigid pose. For true circular bores, verify a supplied finite pin axis through both circles at that pose, including pin radius and required radial gap.
2. For irregular openings, verify pins against the finite source curves or mesh. Compare the substrate outline and populated components with the containing outline. Distinguish plan-view fit, Z interference, installation tool access and connector mating travel. Pairing two boards requires distinct openings across both and mutual hardware clearance. An exhaustive discrete sample only covers its sampled poses. Continuous exclusion requires bounds covering every allowed translation and rotation.
3. For service motion, bind removed and retained part sets, orientation, movement order and travel in the saved assembly frame. Use [service clearance](service-clearance.md) to rule out pairs whose conservative swept bounds remain disjoint. Keep finite-body distances and closest points for other pairs. Separate contact, interference at one pose, continuous obstruction and a mechanically feasible service sequence.
4. For Boolean intersections, use [finite solid contact](../scripts/finite_solid_contact.py) with the optional OpenCascade Python runtime. Require valid closed oriented source solids in a common unit and frame. Check common pieces for validity and closure. Report integration tolerance and convergence per piece. Independently classify a candidate point inside both original solids and measure its distance from each boundary relative to the classifier tolerance. Empty intersections or inconclusive numerical integration alone leave boundary contact unresolved. Preserve failed kernel receipts, inputs and the investigated static pose.

5. Check internal component pairs in a reused subassembly separately from its contacts with the receiving assembly. List intended seats, fits and weld contacts by occurrence. Use conservative bounds to reject disjoint pairs and finite geometry or an interior witness for the remaining pairs where clearance is required. Inspect the exact assembly in a native shaded view before delivery.
6. Compare same-diameter parallel bores as a pattern of expected centres. Coaxial bores at different axial depths can share a projected centre, so also measure their separate rim and blind-end stations or verify the finite cut intervals. For a through pin, use the actual pilot, shoulder and retainer stations to derive the usable grip and withdrawal path.

For a circular retainer inside an annular opening, an overlapping Cartesian bounding box gives a clearance candidate. Check the exact installed solid paths in the opening frame. Confirm the retainer outer cylinder and its end trims, coaxial alignment and actual material boundaries across the shared axial interval. Where the measured outer cylinder bounds the entire retainer across this interval, subtract its radius from the smallest verified opening radius. A positive difference gives a radial separation bound for that interval. Check adjacent bolt passages, seat mouths and shoulders separately when their axial intervals overlap. Keep the screening result and the signed finite-geometry result with the source revision and transforms.

For a centred cross-drilled shaft, run `perpendicular_through_bore` in [feature_checks.py](../scripts/feature_checks.py) before creating the cutter. Supply both finite intervals in the same Cartesian frame. The check returns the cutter overrun and remaining material at each end. Check the bore cylinder and its trim after subtraction.

For coaxial annular faces interrupted by a straight radial keyway, verify the two actual face stations, radii, slot width and end first. Use `annular_seat_with_radial_slot` in [planar_profiles.py](../scripts/planar_profiles.py) when the slot starts at the bore, crosses the contact annulus's inner arc and ends inside its outer circle. Record the calculated projected area after the cut. Contact pressure and preload distribution require a joint model.

### Classify reference occurrences for clearance

1. Inventory all solid occurrences under the checked assembly root. Record the assembly revision, complete root-to-solid paths, composed transforms, units and inclusive bounds. When an exclusion could change a result, identify the exact source revision and source role for the reference insert or solid. Confirm its complete mounted ancestry, expected descendant paths or body identities, and count. Resolve remapped handles through the source definition, role and placement.
2. Exclude only the positively identified nonphysical reference occurrences from the clearance input. Hidden or off layers can corroborate the classification. Physical solids and unresolved occurrences stay in the check regardless of visibility. Keep the reference geometry in the assembly and preserve its complete occurrence inventory.
3. Record the excluded paths and count, remaining physical paths and count, and physical bounds in the same frame. Reconcile the two sets to the inclusive inventory. Recompute finite clearance for the same poses and tolerances from the remaining bodies. Report the inclusive result and the physical result separately when classification changes the controlling clearance.

## Source loops, surface meshes and native recovery

1. Use [source trim loops](../scripts/source_trim_loop.py) for one simple sampled loop in a continuous parameter chart. Follow original oriented edge IDs around each trim. Inverse-map each shared topological vertex once per surface and account for periodic seams explicitly. Report source curve endpoint-to-vertex distances, support inverse residuals and disagreement between adjoining faces separately. Bind face/support identifiers to geometry array hashes when repairing metadata.
2. For a sampled trim, partition grid cells against its actual UV bounds, including small inverse-map fringes. Compare fringe extrapolation and domain-clamped evaluations separately. Whole-fringe triangles can exceed the intended deviation. Check trim coverage, duplicated area against retained meshes, face orientation and independent barycentric interpolation errors. Open interior and boundary patches require a separate closure check.
3. [Mesh checks](../scripts/mesh_checks.py) compute connected indexed components, edge incidence, vertex links, Euler characteristic and signed volume per closed manifold. Record the frame, weld criterion and measured displacement when constructing shared indices. Interpret the signs in an oriented right-handed frame. Separate outward shells, inward cavity shells, self-intersections and nesting according to the body contract.
4. If a holed native Region fails, preserve the original curves, both loop directions and the failed receipt. In a separately identified trial reverse inner traversal, reverse cubic controls and reflect knots within their domain. Verify the same curve locus and original material roles. Use [reversible conditioning](reversible-source-workflows.md) for a caller-declared scale and inverse frame.
5. If extrusion succeeds from an active persisted SAT Region and fails from its reopened SAB representation, record both codecs, source identity, command and output. Save and verify the active compatible Region before the operation. Compare the finished solid in the source frame. Confirm support/control arrays, holes, depth and geometry handles. Count construction entities separately from physical parts.

## Offline check inputs

| Helper call | Inputs and returned evidence |
|---|---|
| `direction_intervals(vanishing_point, picks, radius_px)` | Two-dimensional image coordinates and a circular pick error in pixels. The result contains closed angle intervals in radians modulo π. Zero and π denote the same line. `backproject_line(camera, vanishing_point, angle)` accepts the original 3×4 pinhole projection and returns four coefficients of the world plane. |
| `screen_assignments(board, openings, tolerance=...)` | Supply each feature as a pair of centre XY and enclosing radius in one common length unit. The returned assignments index fixed openings in moving-board order. `finite_pin_witness` takes actual circular bores, angle in degrees, translation, finite pin radius and fixed-frame pin axes. |
| `finite_solid_contact(first, second, ...)` | Two placed Open CASCADE solids and optional candidate points in one common Cartesian frame. Declare distance deflection, contact tolerance, classifier tolerance, witness margin and relative integration target. Integrals have units of length cubed. Run additional targets to compare convergence. The base skill imports without the optional OCP binding. |
| `prepare_trim_loop(...)` | Supply ordered edge uses, oriented edge definitions, shared XYZ vertices in mm, sample order, face and support IDs, UV bounds and independent endpoint/inverse limits in mm. The caller supplies inverse mapping and a checked support evaluator. The returned polygon and residuals describe one simple loop in one chart. |
| `shell_components(vertices, faces, minimum_area=...)` | Supply triangle index triples and vertices in one right-handed Cartesian frame. Declare the area threshold in squared length units. Inspect each component's closed-manifold status before interpreting signed volume. |

## Judge a mating interface

For a projected guard inside a trimmed planar panel, follow the ordered, closed line and ellipse loops of the selected face. Keep all inner loops. Sample each ellipse using its native parameter interval and preserve its endpoint direction. Compute `ellipse_arc_chord_error_bound(major_radius, parameter_step_radians)` for each sampled arc in [planar_profiles.py](../scripts/planar_profiles.py). Compare the whole guard with the sampled polygon and all trim boundaries. A guard contained in the polygon and farther from every trim than the maximum chord error stays inside the corresponding closed loops. Subtract that bound from the reported trim margin. This does not establish clearance to adjoining faces, unsupported trims or other bodies.

For a square-corner hollow section, project the confirmed straight edges from each end plane into its section coordinates. Call `rectangular_opening_perimeters` in [planar_profiles.py](../scripts/planar_profiles.py) with independent inner and outer bounds and a length tolerance. It checks continuous coverage of all eight sides and counts internal seams that span a wall. Check the native solid topology and the end stations separately.

For two straight, hole-free rectangular faces parallel to a coordinate plane, use `rectangular_face_overlap` in [planar_profiles.py](../scripts/planar_profiles.py). Supply independently identified ordered boundary loops in one frame, the shared normal axis and a length tolerance. Read the signed plane offset, projected spans and coplanar overlap area separately. A positive coplanar overlap area describes the common face footprint. Establish the bodies’ material sides and actual seating condition from the source geometry.

For a contact footprint on a complex source body, use `sab_straight_planar_faces` in [native_acis.py](../scripts/native_acis.py) with explicitly selected entity indices from the pinned SAB payload. It reads one ordered straight-edge loop per planar face and checks reachable ownership, closure and plane distance. Project the returned vertices and the candidate footprint into the same plane for containment and edge margin checks. Curved or multi-loop trims require their own boundary reader. The selected faces describe geometry. Contact loads and material suitability use separate inputs.

Identify the two occurrences, affected surfaces, pose, and intended relationship from the job or drawing. A seating face may require contact, a running fit may require clearance and a press fit may specify interference. Compare the appropriate signed linear dimension or diametral fit with the specified range and units. Record measurement uncertainty and kernel resolution separately from the permitted fit tolerance. A common volume in cubic units measures material overlap. For a depth or diametral requirement, measure that length on the identified features. If the job supplies no applicable fit criterion, report the observed geometry and measurement resolution without assigning a fit verdict. Where the measurement interval crosses a specified limit, report the interval and the unresolved decision.

## Carry original STEP assignments into a posed wrapper

When re-export changes a source solid's supports or trims, bind the unchanged source body and representation context to the intended wrapper occurrence. Use `copy_step_closure` in [step_entity_graph.py](../scripts/step_entity_graph.py) with the source reader's dictionary of positive entity IDs and original right-hand-side texts, ordered body/context roots, and the first free ID above every retained wrapper ID. The helper follows internal references through simple and complex instances, preserves repeated references, cycles, comments, quoted strings and scalar spelling, and returns the copied assignments, new roots and original-to-new mapping. The caller supplies already parsed assignments from a single local DATA section.

Reconnect each intended representation and context, accounting for all incoming references before removing placeholder topology. Verify the retained wrapper product hierarchy, units, and transforms and the exact mapped source body/context payloads after writing. Import the result separately, enumerate all intended finite solids and check face and edge families, unique vertices, bidirectional edge samples and volume in the declared frame. Record the sampling and integration controls. Keep the retained source and any failed re-export with the owning job.

### Equal-angle countersunk fit

Use `plate_reference.matching_countersink_fit` after measuring the bore and mouth diameters on the seat and the shank and outer diameters on the head. Verify coaxial alignment and the same included angle for both cones. A positive head setback places the head below the seat mouth plane. The facing cone span measures their shared nominal axial length. This sharp-cone result supplies placement inputs. Use separate measured profiles for fillets, angle mismatch, stand-off and preload.

## Verify an assembly at a second index position

1. Identify the carrier, every part that travels with it, and each fixed support. Bind the same occurrence IDs to both reopened models. Measure complete world placement matrices in a common frame with translations in millimetres. When the adjustable assembly is nested, compose its parent transforms first.

2. Pass both inventories, the moving IDs and the specified world displacement to `check_index_translation` in [assembly_verification.py](../scripts/assembly_verification.py). It measures each moving part against the same displacement and each fixed part against its original pose. Compare native solid payloads independently for parts that retain their shape.

3. At the selected setting, verify the lock shank through each bracket and carrier bore, the actual grip between head and nut, head clearance to the adjacent moving body and material from the bore rim to the nearest free edge. Recalculate working depth and guard clearance against the reference plane in this setting. Keep clearances at other settings with their own model revision and pose.
