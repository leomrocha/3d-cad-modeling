# Inspect and revise an existing pillow-block bearing

Executed case: [SKF SY20TF iteration](https://github.com/leomrocha/3d-cad-modeling/blob/master/execution/c009-bearing.md). Runtime: gpt-6.1-sol, 12 November 2026.

1. **Read existing work:** preserve the source native drawing, its part sheet, previous construction/check report and retained manufacturer documents. Bind each required dimension to a precise source page/label and SHA-256 in the component project's source job. Keep reconstructed seal features and nominal thread representations labelled separately from manufacturer dimensions.
2. **Open and inspect:** use the installed OCS helper and existing FERME `Client`/`Journal`. Preserve other documents. Read document units, actual solid records, metadata component names and native ACIS bytes. Recover an uncertain open/save request by its original request ID; use the actual active document after reopening.
3. **Check source dimensions:** call `pillow_block.check(records, job)`. [The Python helper](../scripts/pillow_block.py) reads the exact component set and compares housing dimensions, mounting slots, shaft bore/height, ring faces, spherical seats, screw positions/nominal diameters/sockets, seal/flinger radii and faces, and grease-fitting dimensions. Expectations belong to the external source job. The 1e−7 numerical comparison threshold describes geometric comparison in millimetre model coordinates.
4. **Read transformed geometry:** [native_acis.py](../scripts/native_acis.py) accepts proper unit-scale rigid transforms, spheres and circular cones only through explicit options. It applies the native body transform to origins, vertices, directions and plane normals. It reports ACIS header units separately. In the exercised SKF case the OCS document uses millimetres and ACIS header metadata reports10; the source-linked checks compare OCS model coordinates.
5. **Recover trimmed boundaries:** native Boolean operations can split one planar mounting face into many fragments. Cancel shared coplanar edges, then group remaining connected boundary edges before measuring holes. Require the two slot boundaries to close and match source dimensions and centres. The retained SKF native records exercise this case.
6. **Record the actual defect:** the original housing crown measures32 mm; SKF dimension A1 gives21 mm. Preserve the failed check, the source and original file. The original construction script already defines a linear32-to21 mm axial draft; its attempted Boolean wedge removal had left the full32 mm crown.
7. **Revise the owned housing:** explicitly select its actual handle and check selection readback. OCS `SLICE` accepts three plane points followed by a point on the retained side. For the exercised source dimensions, the positive plane uses `(0,16,0)`, `(1,16,0)`, `(0,10.5,64.5)` and retained point `(0,0,33.3)`; mirror Y for the other plane. These points express the existing reconstruction's linear draft. Derive other component planes from their own bound dimensions. Check only the housing geometry changed and the other nine native solids remain byte-identical before saving.
8. **Save a derivative and reopen:** use `save_reopen` with a new absolute DWG path and ten-solid manifest. If reopening exceeds the polling bound, recover the original request, refresh the document ID, and finish hash/manifest checks from retained save responses and the reopened audit. Run the full native dimension check again. Capture and inspect front, top and isometric views from the reopened component.
9. **Register the iteration:** retain the original failure and successful derivative checks, source hashes, exact native requests, semantic action occurrences, actual inspected views and the applied helper/skill improvement in their owning repositories. Update the existing component-work record; keep the previous original/check report as historical evidence.

## Reproduce the feature check

Install the pinned [native-reader dependencies](../requirements.txt) into an isolated target and put that target plus this installed skill's `scripts` directory on `PYTHONPATH`. Load the external job and actual retained native record JSON, then call `pillow_block.check(record, job)`. This call reads files and returns checks; CAD modification uses the separately selected live OCS session and guarded journal.
