# Check a straight service path

1. Identify the moving occurrence, the saved assembly and every stationary occurrence in scope. Pin their files and measurement records. Compose nested placements into one declared world frame and length unit. Record the service sequence, released parts, start pose, full displacement vector and required clearance. Include connectors, cables, hands and tools when the service requirement includes them and their geometry is available.
2. Supply conservative XYZ boxes enclosing the represented geometry to `translation_box_window(moving_bounds, fixed_bounds, displacement)` in [service_clearance.py](../scripts/service_clearance.py). Boxes are `[[xmin,ymin,zmin],[xmax,ymax,zmax]]`. Use conservative expansions where the required clearance or measurement uncertainty calls for them. The function checks the continuous interval, including contacts at the start and end. `DISJOINT_BOUNDS` establishes separation for the supplied enclosures. `CANDIDATE` gives a closed interval of possible contact. The two exact rational strings give fractions of the full displacement. Parse them with `fractions.Fraction` before evaluating poses.
3. For a move with fixed orientation, project the moving geometry and stationary obstacles onto the same plane perpendicular to travel. Use complete geometry or conservative silhouettes. When using planar mesh triangles, project each finite face and union the results. Preserve edge-on faces as segments or points so they still participate in contact tests. A positive gap greater than the required margin proves separation throughout straight translation for the checked representations. Touching or overlapping projections require a 3D sweep or another geometric proof. Keep mesh, measured surface and envelope scope explicit.
4. Use `shared_definition_coincidence(moving_matrix, fixed_matrix, displacement)` only after verifying both occurrences reference the same nonempty geometry definition. Supply nonsingular affine 4×4 matrices in the same world frame. Identical linear transforms and a matching translation within the finite path give a `COINCIDENCE_WITNESS`. Record the witness travel and both occurrences. For a solid with positive volume, coincidence proves interference at that pose. `NO_COINCIDENCE_WITNESS` leaves the collision question open.
5. Run a supported 3D test for remaining candidates. A positive-volume intersection at one sampled pose proves interference there. Clear samples cover their tested poses. A continuous clear result requires a validated swept-volume or continuous collision method for the whole motion and all in-scope geometry. Keep unknown bodies, invalid input solids and untested clearances visible in the result. A path with rotation, bending or staged motion needs its own supported method.

## Axial withdrawal through a bore

1. Bind the moving shaft and each fixed obstacle to source solid IDs, occurrence matrices and hashes. Record the initial overlap or gap, the release set, signed travel interval, straight axis and invariant orientation. Match finite cylindrical face centres and axes, diameters and trimmed axial spans at each attachment station. An adjacent hardware solid is a separate pair, even when its axis coincides with the bore.
2. Use `axial_section_window` in [service_clearance.py](../scripts/service_clearance.py) with conservative moving and fixed axial spans, signed travel extrema and nonnegative clearance. The source stations that can approach the fixed slab run from fixed minimum minus clearance minus maximum travel to fixed maximum plus clearance minus minimum travel, intersected with the moving source span. Parse its exact rational strings with `Fraction`. A positive axial gap bounds the separation over the entire specified interval.
3. For one pair of valid closed solids in a common Z-aligned frame, use `axial_bore_clearance` in [finite_solid_contact.py](../scripts/finite_solid_contact.py) with a common XY guard axis, signed Z travel, positive moving and bore guard radii, a positive reserve and classifier tolerance. The helper localizes the stationary material around the whole moving XY envelope and verifies the entire approaching source section fits the inner cylinder and the localized obstacle clears the outer cylinder. An optional source-derived `fixed_ceiling` tightens conservative bounds only after a Boolean checks all localized fixed material above it. Retain counts, input poses and failed guard trials.
4. Report the difference between guard radii and the axial/lateral reserve, each body's maximum imported face, edge and vertex tolerances, and Boolean fuzz. A numerical reserve must exceed the summed recorded budget. Record manufacturing tolerances and other obstacles independently. Re-run for each bore, body, motion interval and release set. A failed guard leaves that interval unresolved. A continuous axial gap or a separately validated guard can cover a later interval.

## Saved service endpoints

Prepare a separate occurrence list for each endpoint. Give every moving, fixed and released occurrence a source identity and an explicit pose in the common frame. Bind the displacement and release set to the service calculation, including fixed obstacles that are omitted from a display subset. After import or save, expand the actual hierarchy and compare transformed vertices, finite face counts and closed-shell evidence at that endpoint. Use `match_world_vertices(..., require_unique_source=True)` in [assembly_verification.py](../scripts/assembly_verification.py) when assigning source identities from geometry. For indistinguishable bodies use independent occurrence bindings. Check root metadata, image inputs and the saved file hash separately. The endpoint checks cover the represented poses. Continuous path evidence belongs to the underlying motion interval and its full obstacle set.
