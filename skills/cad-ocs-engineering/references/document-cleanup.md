# Close completed owned documents

1. Call [cleanup_active_owned_document](../scripts/ocs_document_cleanup.py) with state_reader, client_factory, namespace and explicit owned_documents. Each row binds document_id, expected_path, expected_geometry_revision, construction_copy, dirty_discard_allowed, saved_model_path, saved_model_sha256 and a passing persistence_receipt with saved_path/sha256.
2. Require the task's authorized saved/reopened or explicitly save-only geometry and metadata checks before cleanup, using [persistence operation selection](surface-mesh-recovery.md#respect-the-callers-persistence-operation). Verify actual saved bytes and ownership epoch. Dirty discard is permitted for an explicitly owned completed construction copy. Preserve ongoing work and previous checkpoints.
3. The active route uses exact document and geometry-epoch guards. It recovers an uncertain close using the original request ID and verifies target disappearance, remaining IDs and each other path/dirty flag. A clean untitled replacement can follow a sole-tab close.
4. cleanup_owned_documents orchestrates explicit owned IDs and restart recovery. Inactive clean closure and activation of an owned dirty construction copy are separate opt-ins requiring a caller-serialized exclusive interval. Recheck construction epoch after activation before discard.
5. Inactive close addresses a stable target ID, while the inspected protocol's revision guards apply to the active tab. It provides no inactive target-epoch compare-and-swap. Use only with confirmed installed support and serialized ownership. The normal dirty-tab rejection has a special block-test exception in that protocol; target ordinary model documents only.
6. After inactive close, require native closed ID confirmation, target disappearance, unchanged active ID, exact remaining IDs and unchanged other paths/dirty states. Preserve uncertain operations and post-check failures as separate cleanup results. Saved-model completion retains its own evidence.

A verified save can write a checkpoint while the construction tab stays untitled and dirty. Use the original NEW ownership record to bind that tab path and the final verified save to bind the current geometry revision and DWG hash. Successful closure reports `cleanup_status=CLOSED` and `result=PASS`.
