# Import and check a manufacturer assembly

1. Pin source model identity, configuration, length units, licensing and hash. Inspect existing completed models before importing. Preserve source originals.
2. Bind a new document to the exact completed NEW response through [owned_document](../scripts/cadtools/runtime.py). Inspect installed IMPORT command/action schemas and supply the selected source path through their supported interface. Recover pending requests by their original ID.
3. Read stable paginated entity/block records with [records.py](../scripts/cadtools/records.py). Separate solid definitions from placed instances. Traverse exact block membership and retain occurrence paths/matrices.
4. [step_placements.py](../scripts/step_placements.py) reads supported AP214 identity-target source frames and identifies uniquely reversed placements. Review that source association before [assembly_repair.py](../scripts/assembly_repair.py) applies compare-and-set property changes. Keep definition geometry unchanged.
5. Compare saved native vertices and instance matrices using [small_bms.py](../scripts/small_bms.py) or [native_geometry.py](../scripts/native_geometry.py). Preserve open/closed topology observations and source unit conversions explicitly.
6. Create groups with [assembly_build.py](../scripts/assembly_build.py): exact insertion prompts, source hashes and metadata, declared WCS placement and saved readback. Expand caller records using [assembly_occurrences.py](../scripts/assembly_occurrences.py). Quantity counts inserted leaf parts, independently of their internal solid count. For registered package trees, use `rollup_embedded_parts` with the root ID, the current catalogue records keyed by ID and a caller-supplied asset SHA-256 reader. The result follows embedded references at their exact revisions, multiplies repeated occurrences and counts leaf packages. Compare the resulting BOM with the saved assembly inventory and record any leaf package that represents multiple solids.
7. Source hashes recorded during insertion bind a nested group's exact child record revision. Preserve mirrored-hand quantities, cycles, bounds and incomplete journal evidence. Follow [native views](generic-integration.md), [incremental saving](../SKILL.md#save-work-in-progress) and [document cleanup](document-cleanup.md).

### Replace one occurrence of a shared definition

1. Bind the installed occurrence and replacement stock to exact source revisions and saved checkpoints. Import the replacement as a private definition. Compare child order, stable geometry, source-role attributes and block base before changing the installed occurrence. Record the old-to-new child identity mapping.
2. Refresh the entire affected definition and entity inventory after the last staging edit. A read of one changed child leaves an earlier inventory stale. Simulate only the selected occurrence rebind and removal of the temporary import root, accounting for actual model-space membership.
3. Compare complete projected and original occurrence paths, matrices and effective layers using the explicit child mapping. Require equality for retained attributes and record expected changes separately. Save a structured difference with missing, added and changed paths before the mutation if the check fails.
4. Apply the guarded rebind only after the projection passes. Require the live readback to match the planned occurrence changes and preserve other definitions, transforms, resolved colours and visibility. Save the checked revision and retain the verified import checkpoint for recovery.

### Transfer a verified source solid to an installation frame

Match the imported definition to the source owner's local vertices, face count and closed shell before treating the leaf's local axes as source axes. Verify which siblings the edited root will carry. For one matched leaf under a rigid root, call `root_for_leaf_placement(current_root, current_leaf, desired_leaf)` from [step_placements.py](../scripts/step_placements.py). All three matrices are world poses. Apply the returned matrix to the root via a guarded native placement update. Read the leaf's world pose independently and compare its world vertices and named interface axes with the desired frame. Keep leaf geometry and nested local placements unchanged.
