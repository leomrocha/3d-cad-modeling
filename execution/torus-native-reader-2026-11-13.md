# Native torus surface decoder

Observed 13 November 2026. Decoder implementation, native-token inspection and regression execution: `gpt-6.1-sol`. Component construction and bounded external source inspection: `gpt-6-luna`.

1. **Applied change:** `scripts/native_acis.py` adds explicit `allow_tori=True` support for reachable ACIS700 torus surfaces. It returns centre, axis, major radius and minor radius for every surface patch, using the existing rigid-frame transformation when requested. The default reader retains its supported surface set.
2. **Actual format evidence:** the retained G-140 SAB contains four torus-surface records. Each has a pointer, location vector, axis direction vector, two radius doubles, reference direction vector and surface sense/parameter-bound flags. Four seam points and reciprocal closed coedge partners are present. Token slots were observed from the actual parsed binary records.
3. **Source comparison:** Luna inspected the published [acadrust SAT surface types](https://docs.rs/acadrust/latest/src/acadrust/entities/acis/types.rs.html) and [SAT writer](https://docs.rs/acadrust/latest/src/acadrust/entities/acis/writer.rs.html). Their centre/axis/radii/reference-direction order supports the SAT comparison. The crate declares MPL-2.0; the implementation uses independently written Python and copies no acadrust code. SAT scalar accessor indices and native SAB typed token positions are recorded separately.
4. **Guards:** typed token layout, finite vectors and radii, positive ring-shaped dimensions and orthonormal axis/reference directions are required. Body graph traversal supplies reachable face surfaces; the component verifier checks all patches and connected closed topology against external source expectations.
5. **New tests:** four tests passed: malformed token/geometry rejection, rigid world mapping, explicit option enforcement and offline decoding of all four saved native patches. Test fixtures remain in FERME.
6. **Existing regression execution:** 24 tests ran: 17 passed, four skipped and three errored. Two errors are changed pinned rail-source hashes; one is a missing retained battery record. Running those same three tests with the unmodified HEAD decoder reproduced the same errors. Source originals and component geometry were preserved.
