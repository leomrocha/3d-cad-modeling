It contains no component ID, component dimension or default project path.
2. **Source and model gates:** The code resolves each source feature through caller roots, checks `SOURCE_READY`, validates the annular input contract, checks the exact selected component/configuration row with `model_inventory`, and rechecks source hashes, model inventory, output absence and write receipts before its first mutation. Other configuration and dependency rows remain inventory context when the selected row says `NEW_MODEL_REQUIRED`.
3. **Default mode:** Without `--allow-write`, the runner records a read-only preflight. It imports the saved-body reader before session discovery, reads the selected session state and returns with zero native mutations. The caller supplies all paths and the execution-model identity.
