These are preparation documents for later independent jobs. Each job must preserve the alternative route named by its ID, source each interface, state coordinates and units, maintain component-local frames and record assembly transform, source-tag every geometry field, and report checks against the source record. No shaft dimensions, load rating, fit, material, adapter thickness, brake capacity, fastener selection or final route are selected here.

1. **P12 supported wheel shaft.** Start from its own source drawing or a dimensioned design input. Transfer only actual C009 bore/seat requirements and exact ME0907 motor-side interface if the shaft is a motor connection; do not infer the P12 shaft from the motor model. Map two bearing locations, wheel and brake seats, sprocket seat, shoulder faces, keyways, axial retainer and service access to separate source features. Record the complete axial stack and alternative route branches. Prerequisites: source-backed bearing and mating features, verified local frame, explicit brake/drive route. Check: all diameters, lengths, shoulders, keyways, fits and stack against their source or explicitly labeled custom proposal; no load calculation is part of this shape job.
2. **P12B sprocket axle carrier.** First transcribe the PBR exact pilot, hole coordinates, plate thickness and tooth-plane datum; then derive the P12 shaft connection from that separately source-ready interface. Keep chain-plane alignment as an assembly measurement, and preserve carrier, sprocket, shaft and bearing as separate bodies. Alternatives include an independently supported sprocket carrier route or another route if the discussion rejects this chain stage. Check concentricity/coordinates only against the source drawing; actual proposed machine dimensions must be labeled custom.
3. **P14ME shaft-to-rim adapter.** Use the exact C003 rim-seat geometry from the rim-side work record and exact Keiyama Ø13.5-hole interface. The other face depends on a source-ready P12 shoulder/drive/retention record. Keep Knott D12 spherical seats as a separate wheel variant, with its own fastener seats. Record wheel-face datum, pilot, fastener centers, stack and placement. Check the rim side against the rim drawing and shaft side against the P12 drawing.
4. **P14SM PRO-M ring adapter.** Copy actual ring face, Ø145 h7 pilot, 12×M5 pattern coordinates, O-ring/contact interface and local face direction from the exact PRO-M manufacturer outline; independently copy C003 rim seat. Preserve housing mount holes as belonging to the stationary case, not the rotating ring. The Ø190 drawing circle is not the ring bolt circle. The G-140 seal size is recorded in the input sheet, but the manufacturer outline page gives no mating-groove dimensions; do not create a groove from the O-ring nominal size alone. Check each joint separately and record adapter thickness as a custom input only if supplied later.
5. **P14SL PRO-L ring adapter.** Ring fastener pattern is source-ready: 12×M6 depth 12 on Ø170 PCD, Ø182 h7 ring pilot, and Ø155 central output-face diameter; plus a separate four-M12-through stationary housing pattern on 142 mm square. Copy C003 rim face independently, preserve stationary case mounts separately, and check each interface against its own source labels.
