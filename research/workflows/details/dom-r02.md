# DOM-R02 — Manufacturer STEP component to robot link

Date: 2026-11-12. Classification: analyst assessment under the stated conditions.

**Manual effort 3/5; setup 4/5; computing 2/5.**

Output: One sourced supplier component imported as CAD solid; explicit component record, robot parent/link role and reviewed joint; separate visual and collision mesh; sourced mass/inertial fields; URDF link package. An MJCF source/alternative is produced by the local reference writer, not by the URDF export stage.

## Comparison conditions

Comparison condition: one small-to-medium supplier STEP solid, source revision and rights located, mounting datums measured, target parent frame/joint intent stated, mass and inertia sourced or calculated from volume+density with assumptions. Multi-part gearboxes, closed kinematic loops and uncertain vendor data increase human effort. The output is a robot-description link, not physical qualification.

## Output artifacts

1. Type: component-record; Format: JSON manifest + original STEP; Retained: Original file hash, vendor identity/revision, per-asset terms, units/frame, interface datums and property sources.; Loss or inference: Metadata does not upgrade supplier licence or establish actual part mass/condition.
2. Type: cad-solid; Format: FreeCAD native document + original STEP; Retained: B-rep if importer yields one; STEP unchanged.; Loss or inference: Native feature history usually absent; importer healing may change faces/edges.
3. Type: urdf; Format: URDF XML plus referenced mesh package; Retained: Link/joint tree, joint origins/axes/limits, visual, collision and inertial descriptions.; Loss or inference: URDF consumers may ignore package-specific fields; closed loops and MJCF-only actuators do not map to plain URDF tree.
4. Type: collision-set; Format: OBJ/STL convex meshes or primitives; Retained: Collision hull identities, frames and approximation settings.; Loss or inference: Concave holes/passages and fine details may be lost; visual source remains separate.

## Checks

1. STEP file revision/hash and units.
2. CAD import bounds, mass/volume and mounting dimensions against vendor drawing/measurement.
3. Joint graph tree and axis/origin/limit source.
4. URDF parses; every relative mesh path resolves; joint transforms match FreeCAD assembly.
5. Inertial values are sourced, framed and pass numerical tensor checks.
6. Visual and collision files are separate and generated from the same source revision.
7. Asset redistribution terms are attached to file; packaging does not silently relicense vendor geometry.

## Failure recovery

1. STEP importer fails or units wrong: keep original, inspect AP schema/units and import in independent kernel before conversion.
2. No usable mass/inertia: preserve unknown fields as unknown; do not use arbitrary geometry density.
3. Mounting axis ambiguous: request measured datum or author an explicit design datum; do not fit it visually.
4. URDF importer rejects joint type or loop: use a documented tree adapter or native MJCF with explicit constraint topology.
5. Collision creates false contact: go back to visual CAD; split per-link collision bodies or choose primitives using contact needs.

## Effort and computing classification

1. **Human:** 3
2. **Setup:** 4
3. **Compute:** 2
4. **Human reason:** A single supplier part is quick to import, but choosing its parent, motion, interfaces, tolerance, mass and license requires human evidence.
5. **Setup reason:** CAD import, rights registry, mesh/collider tool and URDF adapter are separate.
6. **Compute reason:** For one part, mesh export, URDF parsing and mass data are small; large assemblies are outside the comparison condition.

## Resources and scaling

1. **Cpu:** CAD kernel CPU; one-link package is modest.
2. **Gpu:** No GPU needed for STEP/URDF; collision decomposition is CPU and can scale with mesh triangles.
3. **Ram:** Assembly feature count and triangle count drive memory.
4. **Storage:** STEP plus native file and separate visual/collision meshes; archive hashes/terms.
5. **Scaling drivers:** STEP B-rep face/edge count; tessellation density; number of links and collision pieces; collision decomposition settings
6. **Variants:** Clean STEP + already known joint and sourced inertial values is lowest manual path.; CAD_TO_URDF joint guesses reduce entry effort but increase review; treat as proposal only.; Multi-solid supplier STEP requires product-tree assembly handling.
