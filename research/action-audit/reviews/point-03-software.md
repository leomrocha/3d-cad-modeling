## Proposed software interfaces and agent responsibilities

The helper names and structured contracts below are proposals, not implemented interfaces. Every result carries source IDs/locators, original and transformed coordinates, units, frame IDs, tool and version, input/output hashes, operation identity and warnings. The agent interprets evidence, chooses source entities, feature meaning and valid alternatives, and diagnoses conflicts. The user determines unresolved design or geometry choices. Software applies declared operations and returns measurable evidence.

1. **CAD-08 — Read and clean vector drawing:** `inspect_vector(source, import_options) -> entity_manifest, diagnostics` reports entity IDs/types, layer, space, block nesting/transforms, units and SVG viewBox/transform evidence. `derive_profile(selection, transform, repair_policy) -> profile, change_ledger, checks` copies selected geometry, reports unsupported types, open endpoints, duplicates, intersections, nesting and before/after bounds/area. Agent identifies drawing view, component and intended outer/inner loops; any closure or curve repair records source endpoints, method and displacement, with threshold justified per feature. Output feeds DOM-03/CAD-09 or directly CAD-15 when appropriate.
2. **DOM-03 — DXF/SVG drawing to constrained profile:** `map_profile_to_sketch(profile, plane, explicit_constraints) -> sketch_candidates, mapping` maps source entity IDs to sketch geometry and declared constraints. Agent associates dimension evidence with the intended feature, identifies holes and construction geometry, and resolves ambiguous scale, shape or intended constraints. Sketcher route emits an editable constrained sketch and solver evidence; direct CSG import emits a profile/CSG handoff only. Record every transform from source view to sketch plane and any flattened 3D coordinate.
3. **CAD-09 — Build and constrain an editable planar sketch:** `apply_constraints(sketch, constraints, source_ledger) -> sketch_revision, solver_report` retains initial geometry, constraint IDs, source locators, values and status. Report solver state, degrees of freedom where exposed, redundant/conflicting constraints, residuals where available and geometric movement after solving. Agent determines intended constraints and whether remaining freedom is appropriate; fully constrained geometry can still encode the wrong feature. Failure to obtain a particular solver diagnostic is a reported capability limit, not an assumed pass.
4. **CAD-10 — Create kernel solid and native document:** `construct_solid(profile_or_parameters, feature_sequence, backend) -> native_revision, shape_report` accepts named features, dimensions, units, extrusion vector or revolve axis/angle and part boundary. It invokes only supported exact kernel operations, records dependent features and checks shape validity, solid/shell count and selected measured interfaces. Agent chooses feature sequence from evidence and reviews failed or unsupported operations. Closed and open profiles have distinct output classes. Preserve source, construction script or native document; OCS entity history support depends on operation.
5. **DOM-04 — Brief/profile to native CAD solid:** `materialize_native(brief, profile, backend_capabilities) -> native_artifact, representation_manifest` connects explicit source-backed dimensions and selected features to the chosen construction method. Software checks input completeness and reports unsupported representation; the agent selects a supported route and reviews the native artifact against evidence. OCS/FreeCAD native, CadQuery/build123d script and OpenSCAD CSG source have separate declared outputs. Feed CAD-13 with exact revision and purpose.
6. **DOM-40 — Script-parametric CAD authoring:** `generate_script(brief, parameters, backend_spec) -> source, dependency_manifest` and `evaluate_script(source, environment) -> geometry, run_report` are proposed. Preserve parameter names, provenance, tool/kernel versions, input hashes, units, frame and any libraries' licenses. Agent reviews design intent and source/feature mapping; software checks parameter types/ranges only where defined, captures compile/runtime failures and validates the resulting representation. Changing a parameter must invalidate and regenerate dependent geometry and checks.
7. **CAD-15 — Render source-defined CSG as a mesh:** `render_csg(scad_source, parameters, tessellation, target_format) -> mesh, render_report` records executable/version, selected backend and settings, invocation, units/frame evidence, inputs and output hash. Agent chooses shape parameters and documented resolution for the intended use. Software independently inspects connected components, boundaries, orientation, degenerates, dimensions and geometry deviations where its inspector supports them. STL unit interpretation requires an explicit sidecar/consumer agreement; do not infer units from file extension.
8. **DOM-05 — Export STEP solid:** `export_step(native_revision, target_schema, adapter_settings) -> step, mapping_report` records source representation, output units/frame, tool and settings, input/output hashes, geometry types and potential losses. Agent selects representation required by consumer and interprets unsupported fields. The OCS mesh writer is a faceted route; an exact-geometry exchange goal needs a separately evidenced B-rep exporter. Preserve source native document/script. Reopen in a separate consumer and compare expected analytic faces, holes, volume, bounds and topology with declared tolerances.
9. **CAD-13 — Verify geometry and saved output:** `verify(artifact_revision, requirements, independent_reference) -> measurements, verification_report` ties every named result to feature, source locator, unit, frame, calculation method and threshold. Read back native shape and separate exported file. Record unsupported query as unavailable; never silently treat it as a pass. Agent assesses feature association, source correspondence and scope of checks. Record valid topology, physical size and native history independently; source acceptance is separate.
10. **CAD-14 — Recover from failed interpretation or geometry:** `diagnose(failed_artifact, logs, dependency_graph) -> findings, affected_descendants` retains source, prior revisions, partial outputs, solver/kernel errors and exact operation IDs. Agent locates earliest invalid evidence, geometry or backend boundary and chooses a bounded correction or asks for needed source information. Software invalidates affected outputs and checks, preserves independent work and resumes from a validated revision. For uncertain OCS mutation, read operation state using the same request ID and completed batch steps before another write.

## Frames, tolerances, and representation

1. Preserve source drawing bytes and entity mapping. Record document units, block insert units and scaling, nested transforms, SVG viewport/viewBox and physical scale, source origin, selected plane, handedness and target frame. Compose transforms in explicit order, retain inverse when defined, and compare known source dimensions after transformation; parser success is not a scale check.
2. Bind each feature to source locator, nominal value and unit, evidence classification and applicable datum. Keep engineering allowance, measurement uncertainty and computational comparison tolerance separate. Only source-provided or explicitly derived criteria supply thresholds; unknown values cause an unresolved test, not a universal tolerance. Numerical residuals from constraints cannot substitute for drawing accuracy.
3. Separate profile curves and closed wires; distinguish native parametric sketch, CSG source, analytic/spline B-rep and faceted mesh. A meshed circular hole has tessellation deviation; a valid mesh can omit a required hole; a kernel-valid shape can encode wrong dimensions. Each check has an explicit purpose and selected feature, and source-to-result mapping is retained across transformations and exports.

## Proposed future tests

1. **Vector intake:** DXF fixtures with two layers, nested insert scale/rotation, entity in paper space, open endpoints, duplicate/reversed edge and unsupported entity; SVG with nested transform, viewBox, physical dimensions and holes. Check source IDs, counts, transforms, selected loops and explicit diagnostics. Ambiguous units or competing loops must stop dependent geometry.
2. **Sketch:** A dimensioned profile with named datum, two possible feature associations, an intentional free degree, contradictory constraints and redundant constraints. Verify source-to-constraint mapping, expected solver state, movement and separate semantic review; wrong-but-consistent geometry must fail source comparison.
3. **Kernel construction:** Rectangle with through-hole, a revolution with explicit axis, separate open profile and coincident/near-coincident Boolean operands. Compare independent dimensional references, closedness, solid count, hole and analytic surface type, topology validity and output class. Verify source geometry and operands are preserved according to explicit flags and record kernel refusal without silently substituting a mesh. Include a changed parameter and regenerated dependents.
4. **Export boundary:** Save native and export STEP through each separately selected adapter; reopen with an independent consumer. Compare feature dimensions, bounds, volume where meaningful, analytic cylinder/hole surfaces, topology, units, frame and counts. Include the inspected OCS faceted writer and a precision-sensitive coordinate fixture. An entity labelled `MANIFOLD_SOLID_BREP` alone cannot pass a valid-solid check; output hashes and settings bind each result.
5. **Mesh and recovery:** Render known CSG at two declared tessellation settings and compare known surface deviation, hole preservation, components, normals and bounds. Include open/nonmanifold mesh, invalid source, failed Boolean, interrupted batch, changed source and uncertain OCS response; verify logs, bounded invalidation, source preservation and operation reconciliation. These are future software tests, not physical validation or author acceptance.
