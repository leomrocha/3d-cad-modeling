## Original upstream documentation

1. [OpenCADStudio](https://github.com/HakanSeven12/OpenCADStudio) — native CAD application used in the illustrated examples.
2. [FreeCAD](https://github.com/FreeCAD/FreeCAD) — parametric CAD application assessed in the tool research.
3. [CadQuery](https://github.com/CadQuery/cadquery) and [build123d](https://github.com/gumyr/build123d) — code-based solid-modeling candidates.
4. [Blender](https://www.blender.org/) — scene and mesh application assessed in the research.
5. [IfcOpenShell](https://docs.ifcopenshell.org/introduction.html) and [Bonsai](https://docs.ifcopenshell.org/bonsai.html) — building semantics and IFC authoring sources.
6. [MuJoCo](https://github.com/google-deepmind/mujoco) — simulation-model handoff source.
